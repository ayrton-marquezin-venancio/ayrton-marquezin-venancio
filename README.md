## 🤖 Customer Churn Prediction com Machine Learning

Projeto de **Machine Learning para classificação de churn de clientes**, desenvolvido com o objetivo de prever se um cliente tende a permanecer ou deixar um serviço.

O projeto utiliza uma base de dados sintética para aplicação prática de conceitos de Machine Learning supervisionado.

Durante o desenvolvimento foram aplicadas etapas de:

- preparação e tratamento dos dados;
- separação entre variáveis preditoras e variável alvo;
- divisão entre dados de treino e teste;
- tratamento de valores ausentes;
- transformação de variáveis categóricas;
- prevenção de data leakage;
- construção de pipelines;
- treinamento de modelos;
- comparação entre Logistic Regression e Random Forest;
- avaliação utilizando Accuracy, Precision, Recall, F1-score e matriz de confusão.

Os modelos alcançaram aproximadamente **74,33% de accuracy**, permitindo também analisar as diferenças entre Precision e Recall no contexto de churn.

**Tecnologias utilizadas:**

`Python` | `Pandas` | `NumPy` | `Matplotlib` | `Scikit-learn` | `Jupyter Notebook`

🔗 [Acessar projeto no GitHub](https://github.com/ayrton-marquezin-venancio/Customer-Churn-Prediction-com-Machine-Learning)
