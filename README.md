## Projetos em destaque

### 📊 [People Analytics — Análise e Dashboard de RH](https://github.com/ayrton-marquezin-venancio/people-analytics-pandas)

Fluxo de exploração, tratamento e análise de dados de Recursos Humanos, com indicadores e dashboard interativo para comunicar os resultados.

**Tecnologias:** Python, Pandas, NumPy, Matplotlib, Excel, HTML, CSS, JavaScript e Plotly.js.

---

### ⚙️ [Automação Assistida de Cadastro de Equipamentos](https://github.com/ayrton-marquezin-venancio/automacao-planilha)

Automação local que compara solicitações com uma base de equipamentos, classifica itens novos e duplicados e auxilia o preenchimento de uma cópia de trabalho no Excel. Inclui confirmações humanas e verificações do arquivo salvo; a interação gráfica permanece supervisionada.

**Tecnologias:** Python, Pandas, PyAutoGUI, Pyperclip e OpenPyXL.

---

### 🔎 [Auditor Inteligente — Qualidade e Análise de Vendas](https://github.com/ayrton-marquezin-venancio/auditor-inteligente)

Auditoria de uma base demonstrativa de vendas para identificar problemas de qualidade, analisar indicadores comerciais e apresentar resultados em um dashboard HTML interativo.

**Tecnologias:** Python, Pandas, Jupyter Notebook, HTML, CSS e JavaScript.

---

### 🌱 [EcoData — Organização e Qualidade de Dados Ambientais](https://github.com/ayrton-marquezin-venancio/ecodata)

Projeto didático de ingestão e organização de arquivos CSV e XLSX ambientais, com verificação de duplicidades e relatórios de qualidade. Os dados usados são fictícios e não representam medições ambientais oficiais.

**Tecnologias:** Python, Pandas, OpenPyXL, Jupyter Notebook e Git.

---

### 📉 [Churn Prediction — Comparação de Modelos](https://github.com/ayrton-marquezin-venancio/Churn-Prediction-com-Machine-Learning)

Projeto didático com dados sintéticos para comparar modelos de classificação de churn. Aplica preparação dos dados, pipelines, prevenção de data leakage e avaliação por métricas de classificação.

**Tecnologias:** Python, Pandas, NumPy, Matplotlib, Scikit-learn e Jupyter Notebook.

---

### 📝 [Classificação de Reclamações com PLN](https://github.com/ayrton-marquezin-venancio/Projeto-Previs-o-Categorias)

Projeto acadêmico em grupo para classificar reclamações textuais em categorias. Explora pré-processamento, TF-IDF, regressão logística, comparação de configurações e análise de erros. Os dados são sintéticos e didáticos; os resultados não representam desempenho esperado em produção.

**Tecnologias:** Python, Pandas, NumPy, Scikit-learn, NLTK, spaCy, Matplotlib e Jupyter Notebook.
